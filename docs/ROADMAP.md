## 阶段退出与降级

- 原版财务或历史股票池不可重建：相应个股历史结果只能标为探索，或缩短至可证实区间。
- 文本时点或 LLM 污染不可控制：先做信息展示与抽取验证，以前瞻模拟检验投资价值。
- 主动模型无净增量：保留信息助手、基础配置和风险监测，不为复杂而复杂。
- 小额成本过高：执行试验报告真实限制，不能放宽风险约束掩盖问题。

恢复位置和未决事项以 [PROJECT_STATE](PROJECT_STATE.md) 为入口。任何阶段升级都更新规格、状态和 Git 历史。
