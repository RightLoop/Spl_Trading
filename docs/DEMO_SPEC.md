# 第一轮 demo 实验规格草案 v0.1

日期：2026-10-15。当前是研究规格，不是已实现功能或完成回测。基准原则已经用户接受；本文多数模型与数据参数为可复审的研究默认值。

## 实验问题

先回答两个问题：受约束的简单量化个股模型是否比宽基基础组合更好；在同样模型和风险规则下，文本信息是否再带来增量。不能把更多股票风险、更多调参或更低费用误当成 AI 信息价值。

| 实验 | 配置与输入 | 比较目的 |
| --- | --- | --- |
| A：基础组合 | 目标 80% 的 510300 与 20% 现金，按共同再平衡规则 | 可实际理解和复现的参照 |
| B：数值模型 | 同一基础配置，可用 0%–20% 净资产持有个股；行情、财务等数值特征 | 相对 A 检验主动数值模型 |
| C：数值加文本 | 与 B 同一模型家族、约束和调参预算，新增可追溯的公告文本特征 | 相对 B 检验文本增量 |

没有新闻的公司不能直接删掉；保留缺失标记及来源覆盖，避免新闻密度筛选改变股票池。B、C 参数可在相同规则与预算下分别拟合，但不能给 C 无限制试验机会。若文本原版和时点不足，C 降级为抽取演示，不能宣称完成严格历史验证。

## 共同条件

| 项目 | 研究默认或已接受原则 |
| --- | --- |
| 虚拟本金 | 各组 100 万元；与 1000–3000 元执行试验分别评价 |
| 股票池 | 当时实际生效的沪深 300 成分，保留退出与退市信息 |
| ETF 案例 | 固定 510300；不声称今天选择的存续 ETF 证明整个 ETF 筛选过程无偏 |
| 股票池时点 | 必须在决策时已知并生效，不以今天成分回填 |
| 配置与换手 | 采用 [投资政策](INVESTMENT_POLICY.md) 的 80/20、75/85 触发、持续恢复任务和普通单边周度 5% 额度 |
| 风险与集中度 | B、C 共享主动预算、个股和穿透约束；资料不足须标注不可验证 |
| 交易模拟 | 同样费用、滑点、停牌、涨跌停、交易日历、交易单位与现金约束 |
| 执行时序 | 信号所用资料必须先可用，再执行；禁止用同一收盘价既产生信号又无条件成交 |
| 现金 | 未确定可用工具前主实验按零收益；单独列有依据的替代情景 |
| 外部存款 | 不放入模型交易账本；整体资产视图另算 |

510300 自上市后才可交易；更早指数代理与真实 ETF 账本分开。沪深 300 指数不是可直接成交的证券。分红、拆分、手续费与分红税不能忽略，复权收益和现金分红也不能重复计入。

## 时间划分与可得性

拟定 2013–2014 年为预热，2015–2019 年训练，2020–2022 年验证，2023–2025 年为保留测试。预热可能因特征窗口而需要更早数据，最终取决于审计结果。2026 年上半年形成的信号，在标签到期后可作近期诊断；它不是自动新增的、反复试验后的“独立测试”。

2026-10-14 是拟定数据参考截止日，不代表已取得该日以前的完整数据库。所有资料按当时可得时间加入；事后更正的数据不能提前使用。

2023–2025 年若被用于选特征、改规则或观察失败后调参，必须转记为开发数据，不能继续保持“未见测试集”身份。从现在开始记录所有试验，不只保留最好结果。全量回放和真正前瞻模拟承担不同证据职责。

## 模型与标签

首轮建议 6–10 个有经济含义、数据可得的特征，候选包括趋势、相对估值、盈利质量、财务变化等；具体列表尚未冻结。银行等行业的财务结构不同，不能机械套用一般企业经营现金流指标。

数值预测先用岭回归等简单正则化模型，避免在小样本上堆叠复杂算法。收益模型估计相对 ETF 的未来总收益，风险模型使用历史协方差与收缩估计，首个候选回看窗口为过去 252 个交易日，仍需检查数据充分性和稳定性。组合层综合预测、风险、成本和约束决定持仓。模型系数来自训练，不能把 LLM 自报的“信心 90%”直接设成收益概率或持仓权重。

主标签拟用未来 60 个交易日相对 ETF 的总收益；20、120 日作为后续预先登记的扩展，不在测试集挑最好期限。周度决策不意味着每周清仓，预测期也不等于保证持有期。

**编码前必须明确：**周度信息截止时间、假期顺延、信号生成时间、最早成交时点、标签起止价、分红归属、不可成交与标签参考收益的区别。可以研究下一交易日开盘成交，但当前尚未最终确认，不能擅自写成既定规则。

训练时只使用标签已经到期的样本，并按实际标签结束时间清除训练与验证交界的重叠。归一化、缺失值处理、特征筛选只在训练数据拟合。重叠 60 日标签不是独立的 60 日试验，推断要考虑时间相关性。

第一轮先冻结收益模型参数与规则再测试；风险协方差可以按预先固定的滚动算法更新。若以后加入定期重新训练，须预登记频率、窗口和标签成熟条件，再整体向前运行。

## 文字信息的专门限制

第一轮优先公告和财报，提取事实、变化、风险条款与结构化主题，不从语言流畅程度产生投资依据。输出须含原文位置、数值单位、期间、可得时间、抽取版本与无法确认项。

拿今天的 LLM 分析历史公告，模型可能已记住后续市场事实。仅提示“假设你在当时”不能消除污染。因此历史文本实验是探索性证据；事实抽取质量可以检验，投资增量还应通过冻结后的前瞻模拟验证。

没有预先定义、当时可得的预期及标准化尺度时，不能把利润同比增长叫作标准化意外盈利 SUE。预期可以来自分析师或事前定义的时间序列模型，但后者不能冒充市场一致预期。案例说明见 [美的年报](examples/MIDEA_2024_REPORT.md)。

## 三类验收，分别报告

### 工程与数据验收

- 输入、时点、转换、模型版本和输出可追溯，同一固定快照可复算。
- 关键账本恒等式成立，分红和费用不重扣，未成交不记已成交。
- 决策使用数据不得晚于信息截止时点；检测到未来信息即该结果失效。
- 股票池历史、原始价格、财务版本等关键输入未通过 [数据要求](DATA_REQUIREMENTS.md) 时，相应实验不进入投资结论阶段。
- 缺失、退市、停牌、修订和接口异常有显式记录，不静默填成零或删除困难样本。

### 投资证据验收

至少报告扣费收益、相对收益、波动、最大回撤、下行风险、敞口、换手、分年表现、成本敏感性和不确定性。B 对 A、C 对 B 都要比较；也保留 C 对 A 的总体差异。

初步可比范围建议实现波动约为 A 的 0.9–1.1 倍、最大回撤不比 A 恶化超过 3 个百分点，并检查尾部和集中度。这是待讨论的容差，不是金融定律；更低风险时不应为凑范围主动加杠杆。只达到波动范围也不代表风险完全相同。

净增量应为正，并且不能主要依赖单一年份、个别股票、低估费用或反复试验。若合理的不确定性范围含零，应写“证据不足”，而不是包装成获利能力通过。复杂度和数据成本也须与增量相称。无需设任意的“胜率 60%”或“年化 15%”作为通用门槛。

### 小额执行验收

1000–3000 元单独核查交易单位、可买数量、目标权重偏离、手续费占比、委托与成交差异、剩余现金和对账。暂不使用这些账户收益判断选股模型优劣，也不把虚拟账户结果伪装成小额实盘可复制。

## 升级条件

通过数据与工程验收后才能进行可解释的历史比较；历史结果合格后再冻结规则做前瞻模拟。未来小额实盘、自动交易与扩大资金是新的阶段，需要明确账户、权限、风控、对账、停机和恢复机制。
