# A 风险状态、订单权限与复审恢复规格

更新：2026-11-03；版本 v0.1。依据 Git `341e38d` 的政策、A账本v0.4、费用v0.2、额度v0.1、数据契约和T-01/G-05。**用户已确认 D-034：回撤超过35%暂停所有自动买入，包括基础ETF补仓，复审后恢复。**这替代此前“仅限制新增主动风险”的建议；40%方向不变。下述状态、时序、恢复观察窗及历史情景均为助手研究建议，已设计未冻结，不能冒称用户逐项批准或实现通过。当前仍只做文档，不运行系统或账户。

主责：风险观测、持续权限限制、异常阻断、减险许可和恢复事件；[账本](A_LEDGER_AND_EXECUTION.md)主责V/U/n和事件，[费用](FEES_AND_GAP_PROTECTION.md)主责成本/保护，[额度](WEEKLY_QUOTA_AND_REBALANCE.md)主责普通预算和配置目标。关联R-04/06/07/09/13/15、MOD-POLICY/EXEC/LEDGER/OPS/UI、IF-03/04/06；T-01/AC-01设计，供T-06/09/10/11/13及AC-06/09/10/11/13使用。RS-01至RS-20为合成验收预期，无系统测试。

## 1. 风控的职责及边界

暂停买入只能停止增加新的持仓，已有权益仍会涨跌。卖出减少未来股票敞口，不会抹掉已发生的亏损；成本还可能使当下回撤略深。40%因此是处置边界，不是保证损失止于40%的保险。

自动“跌到某值就清仓、反弹就买回”本身是需要验证的择时策略，可能错过反弹并增加成本；不将它偷偷塞入基础组合。[Kaminski与Lo研究](https://alo.mit.edu/publications/page/13/)讨论止损作用对收益过程及采样的依赖，未证明我们的阈值有效。当前方案采用买入暂停、留存持仓与明确许可下减险，不自动清仓或亏损后改模型。

专业来源与实际阅读范围见[参考资料第19节](../REFERENCES.md#19-2026-11-03-风险权限与恢复依据)。境外监管资料仅用于借鉴执行不确定性和控制治理，不当作中国个人账户的适用法律，也不据此给用户新增券商权限。

## 2. 三类状态必须分别记录

### 2.1 回撤观测级别

每个合格交易日日末使用包含已确认费用、应收/应付及持仓损益的经济净资产V，绩效份额U和单位净值n。H_n是日末单位净值历史高水位，不是现金限制H，不是ETF份额净值。初始化纳入n_0。

    n_t = V_t / U_t
    H_n,t = max(H_n,t-1, n_t)
    DD_close,t = 1 − n_t / H_n,t

交易日20:30按已有20:00信息截止和事件顺序核对，先得到合格估值再分级。V/U/价格/权利不可靠时输出UNKNOWN及健康阻断，不把缺失当DD=0、沿用旧DD宣称正常或更新高水位。U≤0或V≤0为本范围异常，停止自动交易并复核，不能除零或输出正常策略结果。份额化资金流、中途资金流主情景失效仍按既有契约处理。

| 当前观测级别 | 精确区间 | 含义 |
| --- | --- | --- |
| NORMAL | 0≤DD≤30% | 未达警告；不表示低风险或没有其他阻断 |
| WARNING | 30%<DD≤35% | 生成归因/数据/成本与敞口检查记录；A普通规则可继续，其他许可独立检查 |
| REVIEW | 35%<DD≤40% | 触发复审事件并禁止所有自动买入，含初建、ETF补仓、红利再投资 |
| FREEZE | DD>40% | 升级严重事件，继续禁止买入；复审须增加资金承受力、模型/政策假设和重新规划材料 |
| UNKNOWN | 输入不合格 | 不输出确定等级；已有锁不解除，另加受影响范围的健康阻断 |

沿用“超过”的严格大于关系：恰30%属NORMAL，恰35%属WARNING，恰40%属REVIEW。用计算精度比较，展示四舍五入为35.00%不代表未超过35%；通用精度和边界交叉乘比较在G-01/G-06冻结。

### 2.2 权限锁和事件

`permission_lock`取OPEN、REVIEW_LOCK、FREEZE_LOCK。测得REVIEW将OPEN升级为REVIEW_LOCK；FREEZE将任意更低锁升级为FREEZE_LOCK。可直接跳级，不需先经历警告。市场反弹可降低**观测级别**，但不自动降低**权限锁**；重启进程、模型更名、入金或日历翻周均不清锁。

相同活动事件不每天新建，保存最早触发、每次观测、最高严重程度及风险版本；升级增加事件修订/epoch，使旧恢复许可失效。有效恢复见第5节。只要锁未解，DD已回到20%也不能重新买入。警告不单独锁买入，但保留检查记录；风险警报不是自动修改预测模型的指令。

### 2.3 独立的运行健康阻断

健康状态为CLEAR或一个/多个带作用域的HOLD：关键行情/行动/规则未知、账本不平、订单回报不明、版本冲突、运行未对账等。A为单ETF账户，相关资产估值或账本故障通常阻断全账户自动买卖；卖出也需要可靠数量、权利、价格和费用，不能因叫“减险”就盲卖。

非关键新闻缺失不阻断不使用新闻的A；故障按实际依赖作用域处理。风险锁、健康HOLD、执行合法性及外部授权共同决定权限，解除其中一个不解除其他。真实已有成交仍按可靠回报记账；暂停不等于停止接收回报、交收、核对或保存证据。HOLD解除须有原因闭环和对账证据；数据修正不得静默覆盖旧运行，完整技术恢复程序留G-06/G-13。

## 3. 动作权限与订单失效

下表假设所需数据健康、数量/费用/交易条件合格；不是实盘授权。

| 动作 | OPEN且当前未超过35% | REVIEW_LOCK或FREEZE_LOCK |
| --- | --- | --- |
| 初建/基础恢复买入ETF | 仅合法批次及预算/目标检查通过后允许 | 禁止，即使权重低于75%、额度充足或价格便宜 |
| 普通基础恢复卖出ETF | 周度、普通5%、普通卖价保护、严格改善80%偏离等共同规则 | 同左；暂停买入不等于一律禁止合理卖出，也不自动豁免普通额度 |
| 明确许可的必要减险卖出 | 按第4节，不自动授予 | 同左，不以DD立即改善作为条件 |
| 主动个股/ETF换仓 | A不适用；B/C另定约束 | 所有买腿禁止，不把成对卖买或ETF替换叫作纯减险 |
| 估值/高水位/成本/交收/报告 | 持续记录 | 持续记录，不冻结净值或省略后续亏损 |
| 撤销不再允许的未成交意图 | 按状态检查 | 立即使买入意图无效、取消未成交部分；不能取消已经发生的经济成交 |

同一证券的A纯卖出减少份额与股票名义暴露，只在可靠账本下判断；若费用大到产生无来源净付款，按费用规格拒绝。不能仅以卖后DD更大否定减险，亦不能将卖后可能变现金解释为当下已可再买。

研究撮合按确定事件顺序，风险状态更新/资格检查先于新成交原子提交；禁止买入的锁一旦生效，旧买单不得继续使用旧许可。零成交取消释放F/Z；部分成交则保留已成交q/B/L和额度T，只释放未成交承诺，见LC/FG/QR。未来真实券商撤单请求不是撤单成功，确认前保留相应占用和不确定状态，不以已发撤单请求凭空恢复余额；实际回报与剩余数量仍需对账。

## 4. 必要减险不能成为任意卖出的通行证

**本版没有“DD触发自动卖到某个比例”的规则。**回撤触发本身不生成清仓许可，普通超配卖出仍属普通任务。当前A无人干预历史主场景也不虚构人工减险指令。

为后续模拟/人工介入预留一条最小许可语义：用户确认的减险决定或事前冻结的专项规则，必须给出账户/证券、风险事件及版本、原因、有效起止批次、`q_floor`（本许可不得卖穿的剩余份数）、`Q_cap`（累计最多可卖份数）、审批/规则证据与许可ID。两数量均须非负且符合适用数量规则；未知数量或不支持行动阻断，不能用无限额占位。自动规则必须在运行前明确冻结，不由LLM自由签发。

每个合格日末批次，在许可仍有效时固定 `Q = floor_lot(min(max(q−q_floor,0), Q_cap−累计已成交份数, 可卖未占用份数))`；按下一计划会话只尝试一次，失败到期释放预留，原许可若仍有效则下个合格日末可重评。余量不足一手留原因，不向上取整。A同一会话同证券至多一个卖意图：必要减险优先，已有普通卖单先取消/确认释放，再分配份额，不叠加两张重复占仓的卖单。

A同证券同时至多一项有效减险许可，同许可旧订单未确认终态时不生成新单；在途订单占用的许可份数不能再分配。替换许可须结束旧许可、核对累计成交和占用，不得重报刷新Q_cap。此为单资产最小约束，多许可合并在未来另定义。

执行前再核对许可未过期/撤销、事件版本有效、固定Q未超过当前可卖量/剩余额度且不会卖穿q_floor；检查本单可卖量时计回**本单自身**份额预占一次，其他订单占用继续保留，不能因自己的冻结而误拒。许可剩余数量同样不能因重放或重报重置。条件变化则拒绝，不现场扩量/缩量。不沿用普通5%额度、2%卖价下界或恢复80%的改善检查；仍须交易状态、有效价、跌停/停牌代理、成本和净付款检查。所有本金/费用进入账本与报告，例外成交单独累计，不给普通额度返还或额外配额。持仓达到q_floor、Q_cap用完、许可过期/撤销均停止该许可，之后不自动生成新许可。

q_floor/Q_cap是当前持仓单位下的明确上限，不保证风险统计量下降到某个值，也不自动随入金、拆并份或市场价格调整；条件变更先失效再复核。未来B/C多资产风险下降判定、全账户可卖冲突和专项自动减险算法须在T-02/G-05补齐，不能以A份数下降代替因子/集中度风险论证。

## 5. 复审与恢复候选

用户确认了“复审后恢复”，**尚未确认以下5日/30%具体条件**。建议采用两道条件共同满足，防止价格短暂反弹就重启，又不要求必须回到历史最高点：

1. **客观资格：**最近连续5个计划交易日的合格日末DD均≤30%，相关健康HOLD全部有闭环证据，账本/订单/成本已对平，相关版本固定；A的必要减险许可均已完成/撤销/过期，相关卖单已确认终态，才可解除买入锁。休市不计一天也不断计数；应有估值缺失、DD>30%或相关健康故障则连续计数归零。开盘及实际成交后观测不增加天数，若DD>30%或出现健康故障也归零，之后从下一合格收盘重新计数。未真正发生的假想成交后DD不计入历史或连续计数。
2. **明确恢复决定：**助手形成复审包，由用户对该具体风险事件确认；不是本轮“继续设计”的授权。包内至少包含触发原因、数据/账本健康、损失归因、期间未成交与敞口、现行策略/成本版本、处置后果和恢复范围。FREEZE_LOCK另须重新规划结论；无需一定改模型，维持原方案也须写理由。助手不能自己批准恢复。

恢复事件绑定账户、incident_id/epoch、复审包版本、批准时可知证据、获准范围和**指定下一决策批次**；仅该批次消费一次。消费前再次核验客观条件、当前DD≤30%、无新风险升级/健康故障、政策/策略版本一致；不合格、过期或重复事件均不解锁，需新的有效决定。不将批准倒填到过去某个低点。若批准晚于批次输入截止，不能补进该批次。

有效事件把权限锁转为OPEN并关闭该事件，仍保留全部历史观测、高水位、持仓、累计成本和周额度；只能在下一合法普通批次重新生成订单，旧失效买单不复活。零成交初建任务可继续原ID，已经用过的初建豁免不重开；必要减险许可须先按明确决定结束并核对相关订单，不因买入恢复暗中撤销它。若OPEN状态新发生有效减险许可，其有效期间及卖单未确认终态期间独立禁止A相反买入，不能用此前恢复事件绕过。

恢复范围先限定A基础配置；B/C主动买入的重新开放另需模型/风险复核和独立范围授权，不能从基础恢复推导。5日和30%是待验证的防反复切换设计，不是市场见底判断，不保证及时或盈利。如果卖出后股票敞口很低、现金收益又为0，账户可能长期无法回到30%以内；应如实报告资格长期不满足，需单独重新规划，而不是降低高水位或偷偷放宽条件。

一次性减险许可不是永久降低80%配置目标；若用户意图长期降仓，应另改投资政策。恢复包须说明原许可如何结束；只要必要减险许可仍有效或其卖单未确认终态，就不开放相反买入，避免开发者自行判断目标是否相容。保持原80%政策而恢复普通配置，可能重新买入此前减掉的份额，这一后果须明确展示。

## 6. 日末、开盘和成本跨阈值

日末按第2节更新H_n与观测/锁，再处理恢复事件及普通批次。开盘阶段使用相容行动和准入的O估值，`n_open=V_open/U`、`DD_open=max(0,1−n_open/H_n,last_close)`；不把开盘新高写入正式日末H_n。即使该会话无订单，合格开盘风险观测也可触发锁，避免“恰好没有订单就漏记同样风险”的策略差异。数据不足记UNKNOWN/HOLD，不用当天未来H/L/C/全天量补齐。

开盘真实观测超过35%/40%可升级对应锁，收盘反弹也不自动解锁。只观测到开盘/收盘的方案仍可能漏过盘中跌幅，不保证盘中止损。

买单决策规划和开盘执行各检查一次预计含费后回撤；开盘固定数量δ>0时，用 `V_post=V_open−δ(p−O)−ΔΓ`、`DD_post=max(0,1−(V_post/U)/H_n,last_close)`。若当前权限锁非OPEN、健康不合格或真实DD_open>35%，拒绝；若仅假想DD_post>35%，也拒绝，但只记“拟交易将跨界”，**不生成实际费用/损失，不据此锁存真实REVIEW事件**。决策时同理使用当时相容参考账本、已确定费用；执行时仍重新核验，不按开盘缩量。

卖单不适用“DD_post不得加深/跨35”买入限制；成交费用若使实际DD跨界，正常记账并立即升级锁，不能裁剪费用或删除成交。取消前已真实成交的买单也照实处理；未来真实行情/回报时延可能使风险越界，不能保证事前模拟完全挡住。动作权限检查与行情/账本原子提交的并发、乱序、幂等细节在G-06/G-13落成正式接口。

## 7. 历史实验不能伪造人工复审

建议首版历史共同情景登记为`RISK-H1_NO_SYNTHETIC_APPROVAL`：无真实当时复审记录，不由今天的人工/LLM阅读后续行情决定历史恢复日。触发REVIEW_LOCK或FREEZE_LOCK后保持买入限制到预登记期末；合格普通卖出仍按规则，持仓、分红、费用、风险和估值持续到期末。没有明示减险许可时，不凭空插入卖出；数据不足则保留缺口和结果不可认证，不能把末次净值平推或删除后半段。

这是“没有恢复审批时的机械权限情景”，不是未来人工助手的完整收益预测，也不是收益下界。各组用同一规则/费用与期间，但各自净值决定何时触发，不能强制在同一天冻结，亦不能给主动组选择更有利恢复日。必须报告锁定时长、权益/现金暴露、拒单与全期收益；若风险/暴露差异破坏“相近风险”条件，就写无法据此确认主动增量。

允许另预登记“满足固定条件后自动恢复”的独立敏感性实验，用来量化锁定影响，但它不是人工复审，更不是已获用户授权的未来自动恢复。无风控的简单组合可作单独诊断参照，不能替换主基准或混报收益。规则/模型修改须新版本并保留旧结果；看过测试尾部再选择恢复规则应记录测试污染，不能声称全新样本外验证。当前未执行任何实验。

## 8. 合成验收预期 RS-01 至 RS-20

默认U=1,000,000、历史日末H_n=1，金额为元；除明确异常外账本/输入合格。DD百分数直接由给定V计算；不代表实际市场路径。佣金/滑点已给的例子不再叠加一次。行为须在未来工程中验证，本轮仅做文档与算例检查。

| ID | 场景 | 预期行为 |
| --- | --- | --- |
