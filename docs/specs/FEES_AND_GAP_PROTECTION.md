## 2. 成本情景与单一计费来源

| 参数 | COST-A1 基准候选 | COST-A2 压力候选 |
| --- | --- | --- |
| 双向佣金比例 r | 0.03% = 0.0003 | 0.06% = 0.0006 |
| 每个有成交计费单元最低额 m | 5 元 | 10 元 |
| 包含关系 | 含经手费等佣金内规费，不额外叠加 0.004% | 同左 |
| 另收交易印花税／过户费 | 本范围情景均为 0，保存适用依据 | 同左 |
| 单边不利滑点 s | 2bp = 0.0002 | 4bp = 0.0004 |
| 普通单不利价格容忍度 g | 2%，见第 5 节 | 保持 2%，不随成本加倍 |

“加倍”指 **r、m、s 参数加倍**，各情景先计算再舍入。分币、tick、拒单和持仓路径不同，最终成本/收益损失不承诺恰好两倍。A/B/C 的同类 ETF 共用同一成本版本；未来个股税费另定义，不能为公平而对不同法律费用强设相同。

单笔最低费是固定成本。名义成交金额 1,000/2,000/3,000 元时，单边 5 元分别占约 0.50%/0.25%/0.167%；往返两次约 1%/0.5%/0.333%，尚未计滑点。分母为成交金额，**不是假设 1,000 元现金可买满 1,000 元证券而不用留费**。比例佣金达到 5 元约需 16,666.67 元成交额，小额主要受最低费影响。

滑点是未单独建模的价差、冲击与执行误差的合并占位情景，未用盘口校准，不另叠同义“价差费”。日线不能证明容量/真实成交。基金内部管理/托管费和底层证券交易费用不机械复制为投资者额外扣款，参照 A 账本第 4 节。

## 3. 佣金归并、确认与舍入

研究计费单元保存账户、场所、证券、方向、交易日、研究订单 ID 和成本版本。A 意图只尝试一个会话，不生成跨日有效订单；长期恢复任务 ID 不是佣金归并键。令 M 为本单**累计确认成交本金**，用十进制计算，`RoundCent` 为四舍五入到分（恰半向上）：

    Γ(0) = 0
    Γ(M) = RoundCent(max(r × M, m)), M > 0
    第 k 笔新增佣金 ΔΓ_k = Γ(M_k) − Γ(M_{k−1})

先对累计佣金舍入，再求增量，不对每条回报重收最低额。累计已确认佣金 Γ(M) 不因费用结清而归零；L 仅为未付余额。费用有唯一事件，重复回报不增加 M/L。

- 同一有效订单分笔累计；零成交拒单/撤单不收费，是本情景假设。
- 部分成交后撤余单，已成交费用保留，只释放剩余预留。新报单新计费单元、新最低额；重放同一事件不生成新订单。
- 本金用最终合规模拟价乘数量。本范围 q 为整数，普通买入按有效整手规则；0.001 元报价与 100 份整手使正常本金到分，不能先将单价取到两位小数。特殊碎股/行动金额另受 G-01 约束。
- 合成费用在成交时确认，随 S1 对应成交批次支付。未来真实费用晚到，保留获知时点和调整事件，不伪装旧决策已经知道；错误修复保留旧运行、更正版重算。退款/修订未经定义不得套负成交额进 Γ；受影响对账标未通过。
- 成本版本缺失、包含关系冲突或品种未覆盖，阻断相应用途，不以零费用兜底。

A 第一版撮合仍为整单成交/拒绝；部分成交例检查账本边界，不表示已支持部分成交撮合或券商接口。

## 4. 滑点进入成交价，不重复扣现金

O 为下一会话准入的未复权开盘价，τ 为有效价格步长；在 `OPEN_PRICE_PROXY` 场景中：

    买入模拟价 p = τ × ceil[O × (1+s) / τ]
    卖出模拟价 p = τ × floor[O × (1−s) / τ]

O 自身须符合有效精度，来源冲突先核查。最终 p 必须为正且满足法定价格、方向保护、资金、数量、额度；越界拒绝，不裁剪为恰好能成交的有利价格。既有涨停不买、跌停不卖等条件继续有效，不读当日高低点、收盘或全日量来修正开盘成交。

O=4、τ=0.001、s=2bp 时，买入 p=4.001、卖出 p=3.999，实际有效滑点为 2.5bp。B/R_s、本金和佣金按最终 p；持仓按对应市场价估值。买入时若市价为 O，q×(p−O) 为价差损耗，另有佣金；不能用 p 给持仓估值掩盖损耗，也不能再次扣同一滑点的 C/L。

## 5. 跳空保护：事先承诺预算，开盘只检查

跳空是交易时段之间价格的离散变化。保护防止前晚订单在未知价格下超出接受条件；**不限制已有持仓的隔夜损失，不保证在回撤阈值卖得掉**。

### 5.1 价格尺度与候选容忍度

建议普通买/卖单采用 **2% 单向不利容忍度**：买入有最高价，普通卖出有最低价；有利价格仍须过额度等检查。2% 是明确、非零的首版执行候选，**未证明最优，不是预测/止损阈值**。正式实验前固定主情景，预登记 1%/5% 敏感性情景，报告拒单、目标偏离时长、风险和净收益；不得看测试收益再选最佳阈值作主结果。成本压力不顺便放宽保护。

P_ref 为决策截止时已知、与计划执行日公司行动相容的参考价：一般取决策日准入未复权收盘；若截止前已知次会话现金除息 d，可减 d，仅用于跨日价格比较。保存原价、d、行动 ID 与转换，不提前生成应收/现金。

    买入上界 p_max = floor_tick[P_ref × (1+g)]
    普通卖出下界 p_min = ceil_tick[P_ref × (1−g)]

边界向限制更严格方向取 tick；比较**含滑点最终价 p**，等于保护界可以通过，其他检查仍需满足。参考/转换价非正、未知/冲突/未支持行动不生成订单。截止后、执行前新发现改变价格尺度/权利数量的行动，旧意图失效，待合法批次重评；不重做信号、改变保护价或按新开盘扩量。

例如昨收 3.989、已知每份除息 0.088，相容参考价为 3.901；2% 买上界 3.979、卖下界 3.823。含息昨收不可直接判断除息跳空；拆并份等须另补数量/价格契约，不能照搬减红利。

**必要减险卖单不继承普通单 2% 下界**，避免越跌越不能减仓。仍受有效价格、停牌/跌停代理、可卖量、数据和净付款能力限制，不保证成交。必须有 G-05 允许的原因/状态；不能将一般再平衡自动升格为减险或额度豁免，不新增强平/重启权限。

### 5.2 数量、现金预算和额度分开

前晚冻结目标数量上限 Q_target、本单现金预算 K_budget、G-04 分配的名义成交额上限 W、任务原因、保护价、成本/规则版本和计划会话。首建/必要减险例外须有政策依据，不以任意大数伪装通过。

Q_target 由额度规格的含费整手目标产生；在向该目标改善的候选中选择合法 Q（A 通常为不超 Q_target 的最大可行整手），并满足：

    Q × p_max + Γ(Q × p_max) ≤ K_budget
    Q × p_max ≤ W                 （普通额度适用时）

预算受当时可用现金/政策限制；无一手可行则不下单，不向上凑手或借钱。普通卖单也前晚固定 Q、可卖份额和 W；有利高开导致 Qp>W 仍拒绝。[额度规格](WEEKLY_QUOTA_AND_REBALANCE.md)已提出 W 的执行周、固定分母、预占/释放与任务规则：A买W=Q×p_max，卖W为方向剩余额度；额度Z与本节现金F分账，不以p_min作卖出本金上界。该方案仍待联合冻结。

开盘只检验固定 Q、价格、风险权限、可卖量、Qp≤W（普通额度适用时）和实际购买能力；合法例外仍须验证独立的授权范围和限额。不按未来开盘缩量让失败单通过，也不低开多买。整单失败按 A 账本到期/释放；普通恢复任务到下次合法周度批次继续，必要减险按日重评。

A初建/基础恢复另按额度规格第4.2节检查固定订单在开盘参考价、含费条件下是否严格改善80%目标偏离；否则拒绝而不缩量。普通2%价格保护通过不代表目标检查通过，见QR-17；必要减险不套此目标检查，其他资格仍需通过。

风险规格另检查当前及拟成交含费后DD：超过35%全部停买适用于初建和普通买，不能因F/W充足绕过。仅预计成交成本使DD跨35%则拒绝、不记虚构损失或锁；允许卖出若真实成本使DD跨界则照实入账并升级。必要减险不要求DD立即改善；许可q_floor/Q_cap与有效期须独立核对。

### 5.3 买单预留与部分成交

本单 i 累计成交本金 M、剩余数量 Q_r，F_i 只覆盖未成交部分：

    F_i = Q_r × p_max + [Γ(M + Q_r × p_max) − Γ(M)]
    K_i = C − H − Σ(F_j, j≠i) − B − L = cash_available + F_i

预留时检查总 F 不超限。执行本单时计回自己的 F_i 一次，不动其他单 F。部分成交须满足“本次本金 + ΔΓ + 成交后 F_i ≤ K_i”，且累计实际支出加剩余承诺不超原 K_budget；q、B、L、F 原子更新。已付佣金仍属 Γ(M)，不得用未付 L 替代，否则交收后又预留最低费。撤余单令 F_i=0，已确认 B/L 不消失。预留/释放不改变 V/U/n；释放差额不是盈利或新额度。

### 5.4 卖单费用与 S1 净交收

卖单冻结份额。本笔卖款足够支付对应新增费时，允许在同一 S1 批次净扣，不因 C=0 禁止卖出；不足时仅对本次净缺口检查其他已结算可用现金，缺来源则拒绝。不能借其他未交收卖款/分红支付缺口。单笔部分成交的费用归属明确留痕，不能用后来可能的成交垫付当前缺口。

S1 仍为下一模拟交易日18:00。每笔本金与增量佣金绑定交收批次、原子结清：买入 C 同减本金/费、B/L 同减；卖出 C 增加毛款减费、R_s/L 同减。不是先扣费制造临时负现金，也不再次计费用损失。部分交收有独立子事件，累计不得超额。

C=0、R_s=4,000、L=5 时，保守可买额−5、V=3,995；交收后 C=3,995、R_s=L=0、V 不变。净交收不让未结卖款提前成为购买力；非本笔费用、异常补费及真实可买/可取规则另核。
