## 2. A 到底需要哪些数据

详细语义与失败处理见[数据契约](DATA_CONTRACTS.md)。A 不训练收益模型，自己的账户净值也不是 60 日预测标签。

| 层级 | 数据与原因 | 缺失的影响 |
| --- | --- | --- |
| 必需 | AD-01 ETF 身份及有效交易规则；AD-02 日历及证券状态 | 不知道交易对象、上市/退出或可交易条件，不能认证成交 |
| 必需 | AD-03 未复权价格；估值用收盘价，其他成交参考字段随时序方案确定 | 市值无法重建；不能用指数点位、基金份额净值或复权价格代替场内成交价 |
| 必需 | AD-04 全持有路径相关公司行动；含权利、除息/生效、支付与版本 | 漏分红会把资产分配误当损失；漏拆并份会把数量/价格变化误当收益 |
| 必需 | AD-05 成本、现金收益、交收与可用性情景；AD-06 初始资金、订单、成交和账本事件 | 无法算净收益或买入能力；研究可以用明确假设，不必等开户 |
| 必需 | AD-07 原件/来源、时间、版本、范围和缺失清单 | 无法说明实际用了哪一份证据，不具备复现与准入基础 |
| 条件必需 | ETF 自身成交量/额、盘口，或现金工具、穿透敞口资料 | 声称容量/冲击、现金收益或公司/行业风险约束时才需要相应资料；未取得就限制该用途，不得称已通过 |
| 当前非依赖 | 个股财报与完整成分库、广泛新闻、宏观、分析师预期、LLM 与预测标签 | 不阻断 A 收益账本；B/C 和长期信息助手保留这些需求 |

日线可以作为明确假设的日/周频研究输入，但不能证明开盘能成交全部数量或触及价格即可成交。估值检查与成交模型检查分别进行。完整区间按事先规定的覆盖条件确定，不能事后删除有缺口、难处理或亏损的日子。

## 3. 先分清资产、现金、权利和绩效单位

以下为**拟采用的成交日经济账本**：成交确认时更新经济持仓，用应收/应付衔接之后的现金交收。它是研究账户口径，不直接复制某券商界面的“总资金”字段。证券经济持仓、已交收数量和可卖数量也不能混用。

| 符号／对象 | 单位与含义 | 关键约束 |
| --- | --- | --- |
| q | ETF 经济持仓份额；只随确认成交/行动改变 | 不是目标订单数；可卖数量另按交收/锁定规则确定 |
| P | 对应时点的未复权场内估值价，元/份 | 与报价来源、时点和质量状态绑定，不等于基金份额净值 |
| C | 已记入本模拟现金账户的结算现金，元 | 不包含同一笔尚未结清的卖款应收；冻结资金仍在 C 中 |
| R_s、R_d | 尚未结清的卖出毛款应收、已确认的分红应收，元 | 各自有事件 ID 与剩余余额；转入 C 时必须同步消除相应应收 |
| B、L | 尚未结清的买入本金应付、已确认未支付的费用/税负，元 | 已直接扣 C 的部分不再保留于应付；净额回报需拆清本金与费用，不能再次扣 L |
| F、H | 未成交委托冻结金额、其他暂不可用现金，元 | 是 C 的用途限制，不是损失；与 B/L 预留不重叠 |
| V | 系统账户经济净资产总金额，元 | 包括权利与义务；外部存款不在内 |
| U、n | 账户绩效份额与单位净值，n=V/U | U 是内部绩效计量单位，**不是 ETF 份额 q**；不得用追加资金提高 n |

总金额恒等式：

    V = C + q × P + R_s + R_d − B − L

在无其他资产/负债且各金额不重计的本版范围内，建议可下单金额：

    cash_available = C − H − F − B − L

这里将所有尚未结清买款/费用优先占用现金，不自动给未到账红利、未结清卖款提供购买力。**这是待冻结的保守模拟方案，不是对真实券商可用余额的断言**；某些账户规则可能允许使用已成交未交收卖款，若要支持，须另定义有依据的可用额度及防重计逻辑，不能直接把 R_s 又当 C 加一次。可取款余额另有规则，本版不声称已定义。

负的可用额保留带符号原值，表示在本保守方案下不能新增买单，须核对原因，不能通过截成 0 掩盖问题；**不自动等于账本失衡或借贷**。例如 C=0、R_s=4,000、L=5 时公式为−5，但若有明确净额交收安排，收到卖款并扣费后 C=3,995；这是尚未释放的购买力，不是凭空亏空。是否允许卖出/必要减险应按相应交收、费用与风控规则判断，不能拿买入现金条件一刀切禁止。未来下单还需数量、额度、风险、费用预留和交易状态检查；上述公式只是保守买入现金条件。可卖数量由经济持仓中相互不重叠的未解锁/订单冻结部分扣除，不能因 q 增加就默认当日可卖。

**80/20 是目标，不是每时刻只有两个账项。** 除息后应收尚未到账时，应分别显示权益市值/V、现金/V、两类应收/V、应付/V和可下单金额；其带符号合计为 100%。不得把 `1−权益权重` 标成可用现金。临时应收不会自动改变目标比例，也不触发绕过额度或风控的再投资。

权益权重为 `qP/V`，不能为凑两项合计 100% 而把分母改成 `C+qP`。q 已代表成交后经济持仓，不再另外叠加一份“待交收证券市值”；未解锁/卖单冻结数量扣减须互斥，成交与对应冻结解除同时更新。

## 4. 事件如何改变账本

每个事件必须有身份、经济时点、实际获知/处理时点、来源或模拟情景、关联订单/行动、版本及处理结果。事件驱动是为可追溯而选的账本设计，不意味着现在选定框架或数据库。

| 事件 | 本版建议的记账动作 | 对净资产及执行的含义 |
| --- | --- | --- |
| 初始化 | 现金注资、建立 U；q=0；目标权重只进入政策配置 | 不能免费赋予 80% ETF 持仓；首次买入有真实模拟订单和成本 |
| 委托冻结／撤销 | 只增减 F 或冻结份额；撤销只释放确认未成交部分 | 不凭意图增加持仓；不把冻结或释放当损益 |
| 买入成交 | q 增加；B 增加成交额；按费用确认规则增加 L；释放对应已成交部分 F | 当估值价等于成交价时，V 仅减少已确认费用；未成交部分继续按规则冻结 |
| 卖出成交 | q 减少；R_s 增加成交额；费用增加 L；释放对应份额冻结 | 卖出把证券变成应收，不自动产生第二份资产；登记在册权利单独保留 |
| 买款支付／卖款收取 | 买款支付使 C、B 同减；卖款结清使 C 同增、R_s 同减 | 交收自身不产生盈亏；费用结清使 C、L 同减，也不再扣一次收益 |
| 分红登记 | 按公告条件固定有权份额 e；此时不加 R_d | 含息市值中尚包含该权利，不能提前重复计资产；e 不随支付日 q 重算 |
| 除息 | 按 e×每份分红确认 R_d；适用税/舍入另有依据 | 原价除息落差与应收一起评价；本版无证据时不假定任何统一税率 |
| 红利到账 | R_d 减少、C 增加，必要时更新 H/可用标记 | 仅资产形态转换；不发绩效份额 U；再投资仍须新订单 |
| 更新市价 | 仅用相应估值价更新 qP，保存价格质量和时点 | 市场损益进入 V，不改 U；没有成交也有未实现盈亏 |
| 外部入金／出金 | 按第 6 节改变 C 和 U | 与分红、交易款不同，不是投资盈亏；出金受可用资金约束 |

费用可以分时确认或实付，但每笔已确认成本必须唯一关联；LC 例把费用金额作为给定输入。[费用子规格](FEES_AND_GAP_PROTECTION.md)已建议同研究订单累计计费、分笔记增量、撤余单不退已确认费、新报单新计费；未证明真实券商规则，仍待 G-03 整体冻结，不从例中5元推出全市场算法。滑点若已进入模拟成交价，不再额外扣同一现金费用。

部分成交时，q、对应冻结的释放、应收/应付和新增费用须作为一组完整变动；剩余订单按费用单元重新预留，不能按成交比例机械释放最低费，也不能每个分笔重收最低额。费用子规格第5节已给剩余预留公式；减去累计已确认费用而非未付L，避免交收后重复预留。规则仍未整体冻结。

基金内部管理/托管费用已由基金财产承担；基于真实 ETF 市价的投资者账本不机械再扣同一内部费用。基金净值与场内市价仍不同；用指数代理基金的模型则需另建费用和跟踪假设。本判断的资料及适用范围见 [REFERENCES 第 15 节](../REFERENCES.md#15-2026-10-24-a-基础组合账本设计依据)。

## 5. 事件顺序、缺失与更正

建议日级研究按以下依赖设计；**具体批次与保守资金场景已在第 10 节提出，仍待冻结**：

1. 导入经准入的有效公司行动与交易规则；达到生效阶段才应用。公开时间、经济生效、到账与可用时间各自保留。
2. 除息日，在使用除息后价格估值前确认已有权利的应收；登记日则在该日相关交易/登记处理结束后固定权利。不能仅因事件在文件里排前面就提前发钱。新增应收却继续使用昨收含息价也会重复计权利；若暂时没有相容的除息估值，须标估值受阻，不能据此更新高水位或给外部资金流定价。
3. 成交、交收、费用和到账按冻结时点/顺序号处理；权利以公告及登记规则为准，不能仅用经济 q 猜测边界交易的权利。
4. 在每次外部资金流前先获得符合本版精度要求的估值，再份额化；无法可靠估值就阻断精确绩效更新，不以日末价格反填早晨入金时净值。
5. 收盘估值、对账和政策检查各有明确截止；同一收盘信号不能无条件以同一收盘价成交。

建议非交易日无市场交易时，可在注明价格日期的情况下沿用最近合格价格展示资产，并处理已发生的现金/行动。交易日行情意外缺失不能填 0 或伪造零收益；已有证券不会消失，可保留“估值不完整/陈旧”的展示，但依赖它的精确权重、回撤及正式绩效判定受阻。真实停牌的估值和行动例外另冻结，不能永远声称最后市价可以变现。

同一经济事件重复到达不重复入账；同 ID 不同内容必须进入冲突/修订处理，而非任选最后一条。部分交收有独立子事件与剩余应收/应付，累计结清不得超过原义务；未知乱序事件暂存并说明原因，不能默默丢弃或先支用现金。

修复错误须关联原事件、保留旧运行，并生成有版本的重算结果。修正后的历史账本可重算净值/高水位，但不得静默覆盖原决策时实际可见的记录或伪造当年已知；原结果是否失效要明确。普通重启、更换模型和重新训练不清除高水位。

## 6. 收益、资金流与回撤

建议以账户净资产金额 V 衡量“有多少钱”，以绩效份额 U 排除外部资金流的机械影响，以单位净值 n 衡量“每单位资本的表现”。初始注资设 n₀=1，U₀=V₀；这个标尺不创造收益。

在资金流入前 V⁻>0、U⁻>0 且估值可靠时，外部净流入 x（出金为负）：

    n⁻ = V⁻ / U⁻
    U⁺ = U⁻ + x / n⁻
    V⁺ = V⁻ + x
    n⁺ = n⁻

资金流不更新到更高的历史高水位；资产本身的损益及账户费用改变 n。分红、买卖和交收属于系统账户内部资产变化，不是 x。若有入金手续费，外部资金与账户费用分别记；不能把手续费藏进净入金来抹去损失。

无断点、规则一致的连续绩效段可用 `n_end/n_start−1` 表示累计时间加权表现；子段收益几何连接。回撤沿用投资政策含义，并统一记号：

    DD_t = 1 − n_t / max(n_0, …, n_t)

这里的 n 不是 ETF 自身的基金份额净值，也不是金额 V。时间加权思路用于比较策略；个人资金实际体验将来可另外报告金额损益和资金加权回报，不混为一项。GIPS 官方说明支持剔除外部现金流影响及区分分红/利息，**本项目只是借鉴方法，不宣称符合 GIPS 标准**。

零/负净资产、U=0、全部清户、实物转入或资金流前估值缺失不套除法。全清户后保留旧绩效段与风险记录；后来新注资另建有明确关联的段，不把空档拼成连续盈利，也不以分段规避原风险处置。该例外和实际资金流处理时刻仍须在 G-01/02 补完整。

## 7. 精度、核对与输出

研究建议：保留来源原始十进制价格/金额及单位；计算前做明确单位转换，不先把 ETF 报价四舍五入到元角分。正常场内交易的 q 使用整数份额并按有效规则检查下单单位；公司行动产生的特殊数量单独定义，不能偷偷取整。

现金实收实付和费用应采用来源/契约规定的精度及舍入顺序；不拿“每笔到分”推导全市场统一舍入。高精度绩效 U/n 与 ETF q 分开；显示金额到两位小数不改变内部值。通用数值类型、上限、单位净值精度和容差留 G-01/G-06 冻结，本轮所有整分验收例应精确成立。

应收理论额与实际结清额若差一分钱也不能长期残留或静默抹平；先核舍入/税费/错误原因，依已定义规则形成独立调整和证据。不存在“差额小于容差便记作盈利”的默认规则。

每日产出建议包括：q/可卖量、价格及质量、C、R_s/R_d、B/L、F/H、可用现金、V/U/n/历史高水位/回撤、各权重、当日事件及拒绝原因、净资产变化与外部资金/损益对账、数据/配置/账本版本。若估值不完整，相应派生指标标不可判定，不输出伪精确值。

## 10. A 的决策、成交与资金时间线建议

### 10.1 三类时钟和知识边界

先分清：**市场/经济事件何时发生，数据何时可供系统使用，账户权利何时可交易或支用**。记录 UTC 或带偏移的时间并明确展示为 Asia/Shanghai；日期级数据保留日期精度，不能因为程序需要排序便伪造精确发布时间。只有逻辑阶段的事件使用阶段与顺序号，不能把阶段名转成假实测时间戳。

历史重建按有证据的公开上界及预登记处理延迟构造假设可用时点；前瞻运行按实际收到、校验/必要处理完成的时间判断。两者分别标识。今天重新取得的完整日线不会自动证明当年某时点提供方已经给出同样版本。

本轮建议：A 的结构化公告/规则记录，历史可用时点为可信公开上界加 **30 分钟自然时间处理延迟**；日期级上界用下一自然日 00:00，再加 30 分钟。这个延迟是研究预算假设，未经耗时实测，不能补救版本缺失；B/C 文本抽取延迟在 T-02 另定，共有数值仍需同版本同准入规则。A 日线收盘记录采用“交易日 20:00 已就绪”的单独研究假设，须通过原价/版本/覆盖检查并在运行中披露；没有历史到达日志时不能称为实测准时服务或严格逐条发布时点认证。延迟情景变更须预登记，不能按收益择优。

正式决策输入须满足 `usable_at <= information_cutoff`；前瞻还须实际处理完成不晚于截止。20:00 截止包含恰好 20:00，20:00:01 才就绪的记录进入之后的合适批次。预留至 20:30 的半小时用于账户核对和决策，不允许悄悄把输入截止延长到 20:30。关键输入未就绪或任务未按时完成时跳过本次决策并留原因，不回填原批次。

### 10.2 建议的日周安排

这些是本项目待冻结的研究调度，不是交易所或券商承诺。A 不使用新闻来择时；安排仍为以后 B/C 共享执行接口留出明确边界。

| 时点／逻辑阶段 | 允许动作 | 不允许动作 |
| --- | --- | --- |
| 每个交易日开盘参考阶段之前 | 应用已获知且生效的规则、公司行动；解锁符合有效交易规则的可卖数量；核对前一批次订单资格 | 新应收搭配含息旧价更新净值/高水位；把未到的现金当可用；用未来开盘价重算目标 |
| 下一交易日的开盘参考阶段 | 对前一批次固定数量意图进行一次条件撮合；使用该日未复权 open 及事前成本规则 | 读取该日收盘、高低点或全天成交量来选择开盘订单；假装日线 open 是确定的 09:30 可成交报价 |
| 当日收盘后的账本阶段 | 记录收盘原价与交易；在符合产品登记规则的条件下固定登记权利；保留价格质量 | 用尚未完成的收盘数据做该日已经发生的成交 |

“周”按本地周一至周日归组，普通检查日取**当时可得官方日历版本**中的该周最后交易日。正常周为周五，周五休市时可能为周四；整周休市不产生普通批次，也不累计多次补调仓。临时休市若周四晚尚不知，不允许事后把周四改成已做过的周度决策；受影响批次记跳过。下一成交会话同样按当时日历排定，若后来临时休市，原意图到期，不回填或无限顺延。已知长假则排定到下一个计划交易日；执行前仍须资格检查。

只有证券停牌并不把市场周度检查日挪到它上一次有成交的日期。缺失关键估值时记录该批次受阻；不能回到数据完整的一天补做决策。非交易日可处理已经发生的到账/公告和系统异常、展示带价格日期的资产；不新增普通投资批次，首版回撤指标明确为**日末估值采样的回撤**，不声称覆盖盘中最深回撤。

周末或长假中新出现的资料不进入已经封存的普通投资决定。执行前新获知的停牌、规则变化、行动或既有风险冻结可以否决旧订单，但不能借“资格检查”重新选股或增加数量。历史没有相应获知时点证据时，不能利用事后全日状态来伪造当时已做检查；影响交易的状态顺序无法确定则阻断该笔严格执行结论。首次建仓拟在预登记起始日的合格晚间批次生成；失败后保留初建任务，到下一普通周度批次重新评估，首建额度例外不等于无限自动重试。

### 10.3 下一开盘参考价与固定意图

建议先采用 `OPEN_PRICE_PROXY`：以已生成意图之后的指定交易日未复权开盘价作为模拟成交参考，再施加事前固定的滑点/费用。上交所开盘价定义与 Backtrader 官方模拟说明支持区分“作决定”和“之后的价格”；它们都不能证明本账户按该价成交。日线无法证明开盘盘口深度、排队和部分成交，也不能从日线 open 推出精确撮合时刻。**本模型是条件成交假设，不是拟发送给券商的真实订单类型。**

意图在决策批次封存：证券、方向、固定份数、决策输入版本、原因/任务、指定执行会话、最大本金/费用预算、风险/额度依据和失效规则。数量只由已准入价格、账户、交易单位和预算产生，不用次日 open 重新按 80% 目标定数量。价格跳空使目标权重偏离时如实报告；保护价、tick 与现金预留见[费用子规格第 4–5 节](FEES_AND_GAP_PROTECTION.md)，周界、分母、额度预占及整手目标见[额度规格](WEEKLY_QUOTA_AND_REBALANCE.md)。G-04 已部分细化，仍须与 G-05 风控交叉冻结。

撮合阶段仅用当时有效规则、账户状态、已知约束和该次参考价判断：可卖量/资金不足、交易状态不明或不可交易、开盘参考价缺失、预算不足、风险冻结不允许时不成交；开盘等于适用涨停价的买单、等于跌停价的卖单，首版拟保守判不成交，不拿全天高低价推断排队已成交。其他方向仍须通过自身条件。缺少所需限价/规则证据时也不能默认正常。成本后参考价若越过法定或预设价格保护边界，拒绝而非截成一个更有利价格。费用子规格已补研究计算规则；必要减险卖单不继承普通卖单窄幅保护下界，其合法权限与其他成交限制仍保留。

买入资金判断须释放/转化**本订单自身**的冻结后再核对本金和费用，保留其他订单冻结，避免把同一预留扣两遍；F 的解除与 B/L 的生成须原子处理。不能临时缩量、融资，或把同批次尚未成交的卖单收入当买入资金。实际价超预算的整单拒绝是本模型的保护假设；将来真实执行必须转换成事前可实施的保护委托，并重新验收，不能假定真实市价单可成交后无损撤销。

2026-10-31 新增 A 初建/基础恢复的固定订单目标改善检查：按开盘参考价和相容账本比较交易前、按固定数量含费交易后的80%绝对偏离，只有严格改善才可继续；不改善则拒绝并等待合法批次，不现场重求数量。见额度规格第4.2节和QR-17。必要减险不套此配置目标检查；B/C主动订单须另定义。该检查只使用开盘阶段准入字段，不放宽TC-11未来字段隔离。

开盘代理阶段还应按该参考价、相容行动与账户重算增险前的安全条件；已越过冻结规则禁止增险的边界时否决买单，不能只依赖前晚风险状态。使用此前合格日末高水位进行该次安全核对，首版正式绩效高水位仍按日末更新；安全核对值单独记录，不混称全天或分钟级回撤。具体阈值等号、增险定义与动作留 G-05；这也是代理假设，实际账户须先取得可用报价再检查和发保护委托，不能承诺仍成交于先前的开盘价。

首个 A 日线撮合模型拟为“全量条件成交或零成交”，只尝试一次，不继续寻找当日更好价格；失败意图到期并释放预留，原因永久保留。账本仍须通过 LC-11 的部分成交测试，为更真实模型与未来回报预留能力；不能据账本支持分笔就声称首版模拟了成交概率。再平衡/初建任务与具体订单分离：普通任务下一周重算，必要减险任务每日合格批次重评；发生失败不等于删除已有仓位或自动完成任务。初建豁免须绑定原任务，不得反复新建以绕过普通额度；统计起点维持预登记的注资/运行起点，不挪到首次成功成交日。风险阈值及恢复权限继续由 G-05 定义。

B/C 未来复用这种时序必须预先固定批量订单优先级/分配算法，不能靠容器遍历顺序抢占现金或利用当天卖款给买单融资；这部分留 G-04/T-02，在 B/C 实现前补齐。运行报告同时披露失败意图、未成交风险敞口及代理成交局限，不能只留已成交样本。

### 10.4 交收、可买、可卖、可取分开

“买入后何时可卖”与“卖出后钱何时可买/可取”是不同规则。2019 上交所投教说明股票 ETF 为 T+1 交易；建行官方股票问答说明可用与可取可能不同。两者支持对象分离，不认证 510300 的全部历史、任何用户账户或精确交收时间。本轮未取得中国结算指南正文的完整交收闭环。

为在未开户时继续研究，提出 **S1 保守现金场景**，不改变第 3 节恒等式，也不把它写成真实交收制度：

- 模拟交收日历暂取所选上交所交易日历，单独保存场景版本和“假设”标识，不冒称已核验银行/中国结算工作日历。
- T 成交即时更新 q、B/R_s 与费用 L；对应交易本金及成交时已确认、属于该结清批次的交易费，在模拟日历的下一日 **18:00** 合成结清。费用子规格第 3/5 节已建议按成交绑定本金与增量费用、原子结清；卖款毛额和对应费用净入 C，不重复扣收益。结清前 R_s 不提供购买力；B/L 继续占用资金。真实迟报/追加费用不能倒填为旧决策已知，未定义修订须补契约，不混入本轮合成费用。跨事件批次顺序/异常仍待交叉冻结，不能由遍历顺序造成假资金不足。
- 买入份额的可卖解锁另按有效产品规则处理；普通股票 ETF 的候选为下一交易会话解锁，不以现金交收完成作为同一个开关。次日能卖也不表示当日买入即可卖，亦不表示能提前提钱。
- 仅知道投资者红利发放日 D、无时分证据时，S1 在 D 的 18:00 合成到账且释放购买力，不能在 D 开盘前支用。若公告只说明给代销/结算机构划款而没有投资者发放安排，不能套用；支付日未知、延迟或金额冲突保留应收并阻断精确资金可用结论。前瞻/真实账户须等待实际确认，不能按公告自动冒充到账。
- 本版主实验无中途出入金，不定义真实可取余额。LC-06/07 是份额化领域例，不能据可下单金额推导可提现金额；将来启用提款先补独立规则。

例：若周一卖出 1,000 份×4 元、费用给定 5 元，其他现金为零，则成交后 R_s=4,000、L=5、V=3,995、保守可买额为−5；周二开盘仍不能用这笔卖款买入。周二 18:00 净额结清后 C=3,995、R_s=L=0，V 不因结清变化；资金最早可支持周二晚已获授权的决策、周三的成交批次，**A 的普通调仓仍须等对应周度批次**。周五成交则下一模拟交易日才结清，不能把 T+1 写成周六。

S1 便于验证“没有提前花钱”，却可能改变持仓路径及 B/C 的换仓效率；延迟资金释放并不在所有市场路径上降低收益，不能称为严格收益下界。A/B/C 正式比较须共用场景并报告现金等待/拒单；获得有依据的可用额度规则后另做预登记对照，不只给主动组便利，也不为省事强制所有卖款延迟方案等同实盘。
