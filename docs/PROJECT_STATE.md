## 已接受的主要决定

| 项目 | 当前约定 |
| --- | --- |
| 愿景 | 个人金融助手，覆盖信息、数学分析、研究与未来交易 |
| 首个市场 | A 股及境内基金和 ETF；首轮集中股票与股票 ETF |
| 投资尺度 | 半个月至半年与几个月至几年的组合；不属于行业意义的高频交易 |
| 资金期限 | 至少五年没有计划取用安排 |
| 收益目标 | 相近风险下，扣除成本后优于简单投资组合 |
| 目标资金结构 | 系统管理约 76.9%，外部存款约 23.1% |
| 存款收益假设 | 用户提供固定年收益 2.5%；外部单独核算 |
| 研究基准 | 系统账户内 80% 权益、20% 现金 |
| 起步资金 | 1000–3000 元，只先验证小额执行；尚未开户 |
| 个股研究 | 保留在虚拟账户中，不能为小额实盘而放宽集中度 |
| 普通再平衡 | 周度检查；触及 75% 或 85% 权益比例后触发，分步回到 80% |
| 优先级 | 必要减险与异常处置，其次基础再平衡，最后主动换仓 |
| 普通换手 | 再平衡与主动换仓共用每周 5% 单边额度；首建和必要减险另记 |
| 开发阶段 | 先讨论、审计与记录，不急于写代码 |

回撤规则、计算口径及例外见 [投资政策](INVESTMENT_POLICY.md)。技术参数中的研究账户 100 万元、个股预算和集中度上限、预测期限、实验日期、波动与回撤比较门槛等，是已提出的研究默认值，不能一概写成用户逐项批准或已经验证。
