# 数据用途准入表 v0.1

日期：2026-10-21，Asia/Shanghai。状态：**研究默认规范与现有证据的用途判断**，尚未冻结正式实验，也未实现数据管线。本轮整理既有审计并查阅专业资料，没有新增行情/财报 API 样本、训练模型或运行回测。用户已接受的投资政策不变。

本表回答“这份数据现在能支持什么判断、升级前还缺什么”。它不按 API 品牌整体认证，也不把理论依据当成本项目数据已经合格的证明。具体历史证据保留在各轮审计中。

## 1. 准入的对象与五种用途

准入对象是**来源＋字段与版本＋证券范围＋时间区间＋转换方法＋用途**。同一接口的收盘价可用，不代表成交量、复权因子和公告日期一起通过；一个年份的三个证券通过，也不代表全市场十年通过。

| 用途 | 要回答的问题 | 最少需要的证据 |
| --- | --- | --- |
| U1 人工阅读与展示 | 这份材料说了什么，何时、关于谁？ | 来源、对象、版本、观察日期、事实/意见区分、缺失与陈旧程度；历史图不能冒充实时状态 |
| U2 有限计算与教学 | 这个公式和数据转换是否算对？ | 明确样本、单位、公式、假设与可复算结果；只能说明该例，不说明预测有效 |
| U3 历史决策输入 | 当时能否用它选股、估风险或决定交易规模？ | 身份、数值语义、当时可得版本、处理完成与决策时序、必要覆盖、转换规则；包括预处理和模型参数的训练时点 |
| U4 历史比较与绩效评价 | A/B/C 的差异是否有可信证据？ | U3 加历史资产池、标签成熟、公司行动、账本、成本、同条件比较、时间切分和试验记录；单字段通过不足以使整个实验通过 |
| U5 模拟执行与风险核验 | 这笔单在假定规则下能否提交、成交并满足约束？ | 可交易状态、订单时序、单位/余额、费用、成交假设和所依赖的风险敞口；输出仍是模拟，不是实际成交证据 |

这五项不是必须逐级通关的阶梯。例如，正式的交易日历可以直接支持日期计算；公司财报不会因为无法用来撮合订单而“不合格”。U5 通过也不授予实盘权限；实际运行还需要账户权限、实时有效数据、成交回报、对账及另行阶段授权。

### 当前状态的读法

- **限用**：已有证据支持下表写明的样本或用途。不能扩大到完整历史、实时状态或正式策略结论。
- **待准入**：尚缺具体条件，当前不用于该项正式判断；不等于永远不可获得。
- **—**：不是这一用途的直接数据。若通过模型间接影响该用途，其依赖仍须验收。
- **禁用方式**单独列出：这是已知会错误使用数据的方法，不能靠“探索性”标签把结果包装成正式投资证据。

“研究默认假设”与“限用实测数据”另外标识。已公开费率可以支撑费用情景，但假设佣金、滑点或到账时间不能被称为个人账户实测。当前没有整套 2013—2025 数据通过 U3—U5 的正式验收。

## 2. 判断依据：六个检查维度

| 维度 | 判断方法 | 为什么影响金融结论 |
| --- | --- | --- |
| 身份与经济含义 | 对上证券、份额类别、指数、报表范围、期间和字段定义；价格、净值和指数点位分开 | 对错对象或口径后，计算即使正确也回答了另一个问题 |
| 数量与单位 | 保留原值、单位、规范化转换、舍入；价格/数量/金额交叉核对 | 容量、费用、估值分母和分红金额会被数量级错误放大 |
| 知识时间与版本 | 区分观察、公开、生效、实际采集和处理时点；原版与更正并存 | 今天真实的数字可能在当年未知，造成前视偏差 |
| 覆盖与样本选择 | 按年份、证券、行业、进入/退出及修订事件报告覆盖；说明分母 | 只剩好取、仍存续、新闻多的公司，实验对象会悄悄改变 |
| 测量与用途契合 | 明确它是实际值、代理、估计、理论收益还是成交假设；沿依赖链验收 | 估计持仓不能证明精确限额，日线不能证明排队成交，指数收益不等于基金账户收益 |
| 可追溯与可持续使用 | 来源/许可、记录版本、转换与失败原因、可复算快照、运行新鲜度 | API 成功与内容可信、研究可复现、持续运行是不同条件 |

研究默认不使用统一“99% 正确率”放行。少量错时版本就可能制造收益；关键缺口按受影响的用途阻断。多个网页数值相同也不必然是独立验证，可能来自同一上游。正式复现应保存许可允许的原始快照；当前摘要和哈希不是完整离线数据库。

## 5. 从数据到数学模型：需要额外检查什么

以下是研究规范，不是已经训练出的模型或收益证据。

### 5.1 输入必须属于当时的信息集合

把决策截止时可用的信息记为 I_t，则输入 x_t、股票池及模型参数都只能依赖 I_t。历史重建采用有证据的公开上界和统一处理延迟；前瞻运行等待实际采集、校验、抽取完成。成员资格还要满足生效条件。完整细则见[时间与版本准入](ASOF_DATA_POLICY.md)。

例如，一份报告描述 12 月末，不代表 12 月已经公开；一条更正虽纠正 2023 年数值，仍不能在更正前被模型看到。任意加 90 天也不能挽救一份没有历史版本证据的最新表。

### 5.2 公式的合理性不能补足输入缺口

市值＝适用价格×适用股数；估值再把市值与相应利润、净资产等比较。每一项都须是所声明时点和口径，不能把历史价格乘今天股本后称为历史市值。原始美股因子中的年度配对方式可以学习，不能直接证明 A 股固定滞后一定足够。[P3](#p3-因子的经济定义与构造)

动量、波动、协方差也不是“只有行情就一定可算”：需要统一收益定义、交易日、公司行动、有效样本和缺失规则。停牌后延用旧价可用于有标记的估值假设，但不能把它解释成可成交价格；长段不变价格还可能低估测得波动。协方差收缩缓解估计噪声，不修复错价、错误单位或未来信息。

同样，数量单位的固定常数有时会在相对量中抵消；但订单数量/成交量这种参与率要求量纲相容，且事前只能用已知量或预测量。无单位验证的容量模型不能被“相对量可能抵消”放行。

### 5.3 输入、标签、预测和仓位分别准入

拟定标签是股票未来 H 个交易日总收益减同区间 ETF 总收益，H＝60 仍为研究默认。训练截止时必须已经观察到完整结果并能取得相应标签；端点、再投资、停牌/退出和跨切分重叠仍需冻结。不能随机打乱时间关系后把结果称为顺序历史决策验证。

预测收益与风险估计是模型输出，须另有训练快照、样本外误差、校准和版本记录。它们不是原始事实，也不是数据准入即通过的产品。LLM 自报信心、情绪分数与回归输出均不直接变成持仓；组合层仍须检查成本、风险与预算。

### 5.4 代理和缺失的处理不能偷偷改变实验

披露 ETF 持仓可作带陈旧程度的估计；若某项约束需要精确当日敞口，应使用证据充分的测量或有依据的保守上界。无法得到有效上界时，阻断依赖该项的交易判断，不能称“近似合规”。保守假设也须说明范围，不能随意给未知敞口一个看似安全的数。

缺失需区分真实零、不适用、未公告、版本缺失、接口失败、暂停交易等。对非关键特征可按预登记规则置缺失、回退或删除该特征；不能只删除难取数据的公司、年份或失败策略。B/C 共有数值版本与资产池一致，C 无新闻不删除股票。若用前值延续，记录年龄并事前规定陈旧阈值，不能无限延续。

### 5.5 当前明确禁用的方式

- 把今天成分、今天股本或最新更正财务值当作当时可得信息，回填历史决策输入；注明“事后值”只能支持相应用途的展示或反例计算，不能绕过正式准入。
- 用同一收盘价同时产生信号并无条件记成交；用事后全日成交量预先决定盘中订单规模。
- 把未知持仓/停牌/退市结果填零，或让缺少后续价格的仓位从账本消失。
- 用复权价格计算真实成交额，或在已含分红收益上重复加入同一现金分红。
- 用全样本拟合标准化、插补、特征选择等变换，再把测试段称为独立验证；时间切分工具也不会自动处理财报版本和跨证券标签重叠。
- 把模型自报信心、论文回报、数据准入状态直接映射为买卖权限或持仓比例。

## 6. 与 demo 的关系及推荐采用顺序

| 层次 | 当前可以推进的设计工作 | 开始正式比较前的依赖 | 不必等待的无关条件 |
| --- | --- | --- | --- |
| 信息助手/证据卡片 | 为已有公告、行情样本做来源明确的阅读与数值教学；设计人工复核字段 | 扩展到实际信息服务还需采集、去重、抽取评估与运行记录 | 不必先证明选股模型有超额收益 |
| A 基础组合 | 先写账本、时序、费用和异常场景的验收例 | 所选 ETF/现金方案的身份、价格、公司行动、日历/交易状态、成本、模拟账户状态与共同规则 | 收益账本不依赖全市场个股财报或个股成分历史；无需为 A 人为增加个股财务输入 |
| B 数值主动模型 | 根据准入条件挑少量有经济含义的候选特征 | A 共用基础，加历史个股池、所用特征的原版/时点、个股行动/退出、风险模型和必要穿透约束 | 不必先有全网新闻、分析师预期或宏观完整库；不用的字段不成为门槛 |
| C 文本增量 | 先定义事实/事件抽取任务和人工标注审阅 | B 共用条件，加原文时点、文本覆盖、抽取误差、版本与延迟公平性；历史 LLM 污染另列限制 | 不需要一开始建设复杂知识图谱或多代理自动交易 |
| 小额执行模拟 | 保留 1000/2000/3000 元整手与费用场景 | 具体品种交易规则、余额、费用和明确撮合假设；实际账户以后另核 | 不以放宽个股集中度解决小额不可买问题 |

若对 A 的评价另包含穿透风险限额，也须验收相应暴露数据或有依据的保守界；“账本不需要”不能扩大为“任何风险评价都不需要”。选中固定 ETF 的案例也不能外推为已验证全市场选基能力。

**建议结论：**优先完善 A 的数据与账本规格；B 的价格/风险类候选先写定义，财报类逐项看原版和口径能否满足；C 先验证抽取质量。宏观、广泛新闻、一致预期和复杂盘口暂不成为首版必要依赖，也不从长期愿景删除。没有证据的字段可以暂缓，不能因此暗中改变已接受的 80/20、换手和回撤规则。

若完整区间不可满足，可事前按覆盖证据缩短日期、去掉非关键特征或把某项降为探索，并记录其改变了什么研究问题。不能看完收益后再选择最有利区间。已知数据缺陷使某结果失效时，保留旧结果与原因；修订后的结果不能继续假称从未看过测试区间。

## 7. 后续逐项准入记录与退出条件

每个候选数据项建立一条记录，至少包括：

1. 类型 ID、字段与经济定义、直接用途及下游依赖、适用 A/B/C。
2. 提供方/端点/许可、原件与版本、证券/日期范围、实际覆盖统计及其分母。
3. 观察/公开/生效/采集/处理时间、时间精度和上界假设。
4. 原单位、转换、公式、异常与缺失/冲突处理、源间独立性。
5. 已核样本、未决项、各用途的当前准入状态、升级所需证据。
6. 决策日期、审阅依据、研究假设、变更原因及 Git 版本；实际实现后再补运行快照。

当前不设虚假的统一覆盖率阈值。对必要的身份、日期、价格、持有路径行动和交易状态，应在选定范围内逐项解释所有缺口；不能把少数致命缺口藏在总体覆盖率里。对可选特征，缺失可在预登记方法下处理，但必须按年份、行业、证券退出/修订等维度呈现，检查是否改变样本。

下一步交付：**A 组合数据依赖与账本验收清单，以及首批候选特征卡片**，逐项列经济机制、公式、时间窗口、数据 ID、缺失规则、预期失效条件和比较方法。候选不等于最终采用，不为达到 6–10 个数量而放松准入。本轮完成的是准入规范，不宣称缺口已补齐或实盘已获准。

## 8. 专业依据与适用边界

下列资料用于解释判断方法；当前样本状态仍以本项目审计为准。仅查阅文档/论文，不代表运行了相应 API、安装框架或复现论文。

### P1 历史可用性与修订版本

[ALFRED 官方帮助](https://alfred.stlouisfed.org/help)正文已读。其保存经济数据的历史发布批次，并说明发布日期取自原来源、提供方或首次进入 FRED 的日期，尽可能核对旧版。这支持区分“过去的观察值”与“当时公布的版本”。本项目采用有标注的公开上界属于研究判断，不表示中国数据已经具有同样覆盖，也不照搬其更新时延。

### P2 样本与统计检验

[Shumway（1997）退市偏差论文](https://onlinelibrary.wiley.com/doi/10.1111/j.1540-6261.1997.tb03818.x)仅核查出版社摘要与书目信息。研究指出美国数据中负面退市收益的遗漏会影响结果。对应本项目的要求是：保留股票名字还不够，持仓退出的经济结果也要记入；不能照搬美国损失估计给 A 股统一补值。

[scikit-learn 泄漏说明](https://scikit-learn.org/stable/common_pitfalls.html)相关正文已读：预处理、插补和特征选择的拟合也须隔离测试数据。[时间序列切分文档](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)说明避免未来训练、过去测试。它们不自动处理本项目跨证券面板和重叠收益标签；按标签实际结束时间隔离属于本项目设计要求，不能简单设 `gap=60` 即宣布无泄漏。协方差等滚动估计可按预先固定的规则使用决策前可得数据，不把整个测试期一次性用于估计。

已有的回测过拟合、多重检验参考见[参考资料第2节](REFERENCES.md)。数据合格后仍须限制调参、登记失败尝试和保留测试边界；准入本身不保证投资增量。

### P3 因子的经济定义与构造

[Kenneth French 官方变量定义](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/Data_Library/variable_definitions.html)正文已读。它明确市值的价格/股数构成，并给出价值、盈利和投资指标的期间配对。本项目借鉴的是“公式、期间和分母必须明确”，不照搬美股定义或推定其在 A 股具有预测力；固定财务滞后也不替代原版公告核验。

### P4 交易成本与成交模型

[cvxportfolio 官方成本文档](https://www.cvxportfolio.com/en/stable/costs.html)相关正文已读：成本模型涉及交易规模、波动与市场成交量，事前优化使用量预测；默认股票参数针对美国流动股票。本项目据此区分实际量与事前量、费用假设与测量，不采用其默认参数作为中国账户事实。该文档也区分已含分红收益与额外分红项，支持防止重复计入。

[LEAN 股票成交模型文档](https://www.quantconnect.com/docs/v2/writing-algorithms/reality-modeling/trade-fills/supported-models/equity-model)相关正文已读：其成交条件显式考虑行情区间、订单时点和交易时间。本项目借鉴“撮合必须显式建模”；这些是引擎的模拟规则，不是 A 股交易所承诺，更不能认证我们的日线能还原真实成交。

### P5 语言模型与历史文本

[Glasserman 与 Lin（2023）](https://arxiv.org/abs/2309.17322)本轮核查原论文摘要与版本信息，未读全文。其区分历史结果记忆与公司背景知识对情绪判断的干扰，偏差方向不必总是抬高收益。本项目因此将历史文本抽取质量与投资价值分开检验，并保留现代 LLM 的历史污染限制；匿名化和“假装回到过去”的提示都不构成已消除污染的证明。论文样本不认证中文公告或 A 股效果。
