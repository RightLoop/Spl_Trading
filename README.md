# Spl Trading

面向个人投资者的金融研究与投资决策助手。项目将信息聚合、可追溯的 AI 信息提取、数学建模、组合风险管理、历史回测、前瞻模拟和未来受限实盘连接起来。

2026-10-21，按用户要求将已有讨论整理为开发资产：文档对应需求、模块、任务及验收，后续实现与系统搭建由助手负责。当前仍先完善规格，不开始编码。

## 核心约定

- 主要目标是在相近风险下，扣除成本后优于事先确定的简单投资组合。
- 首轮研究基准为系统账户内 80% 权益、20% 现金。
- 个股与 ETF 均纳入研究；1000–3000 元起步资金先验证执行可行性，个股保留在虚拟账户研究。
- AI 输出需要同时服务人工阅读和数值特征构建；收益、风险、权重和账本由明确的数学与计算规则处理。
- 已接受的决定、研究默认值、待验证假说和实际证据分别记录，不把回测或论文结果表述为盈利保证。

## 记录规则

重要讨论先更新对应规格，再更新决策记录与当前状态，以 Git 提交保留有意义的里程碑。已废弃的假设保留修订原因，不在新版本中悄悄覆盖。

每次讨论回复末尾附落地卡片；开发前列依据、假设和缺口，开发中先修文档冲突，完成后回填真实文件与验收结果。文档完成、数据通过、实现通过和投资有效分别记录，具体规则见 [WORKFLOW](docs/WORKFLOW.md)。
